## Overview

A semi-automated pipeline for finding and applying to internships, so the repetitive parts run themselves and I spend my time on the parts that need judgment.

## What I built

It pulls roles through ATS APIs, drafts tailored materials with the Claude API, and runs the whole thing on a schedule with GitHub Actions. I stay in the loop on what actually gets sent.
